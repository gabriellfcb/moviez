# MovieMind

Projeto de jogo de navegador onde o usuário tenta descobrir o filme secreto do dia.

## Tecnologias
- HTML
- CSS
- JavaScript
- JSON

## Como executar
Abra o arquivo index.html em um navegador.

## Funcionamento
O sistema escolhe um filme diariamente e compara os palpites do jogador através das características cinematográficas.
