# Relatório Técnico - MovieMind

## Objetivo
Aplicar conceitos de programação e estruturas de dados em um jogo interativo.

## Estruturas utilizadas
- Lista de filmes em JSON
- Busca por nome
- Comparação de atributos

## Funcionamento
O usuário realiza tentativas e recebe feedback visual indicando quais características coincidem com o filme secreto.
